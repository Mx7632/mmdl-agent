# MMDL-Agent 开发指南

本文档详细说明如何编写 Tool、LangChain/LangGraph 的作用，以及后续代码补充方向。

## 📚 LangChain 与 LangGraph 的作用

### LangGraph 的作用

**LangGraph** 是一个用于构建**有状态、多步骤 Agent 工作流**的框架。

#### 项目中的使用：

1. **动态规划工作流**（`app/core/graph.py`）：
   ```python
   graph = StateGraph(DetectionState)
   graph.add_node("planner", planner_node)        # 智能规划
   graph.add_node("executor", executor_node)      # 工具执行
   graph.add_node("consolidate", consolidate_node) # 结果整合
   graph.add_node("answer", answer_node)          # 生成回答
   
   # 定义动态循环
   graph.add_edge(START, "planner")
   graph.add_conditional_edges("planner", router) # 根据规划决定执行工具还是回答
   ```

2. **状态管理**（`app/memory/state.py`）：
   - `DetectionState` 记录了 `intermediate_steps`（中间步骤）、`tool_outputs`（工具输出）和 `loop_count`（循环计数）。
   - 采用“后写覆盖”策略确保状态在循环中正确更新。

### LangChain 的作用

本项目深度集成 LangChain 以实现智能体能力：

1. **Tool-Calling (工具调用)**：
   - 将工业检测能力封装为 `BaseTool`（如 `VisualAnomalyTool`, `TimeSeriesAnomalyTool`）。
   - Planner 使用 `llm.bind_tools()` 动态决定下一步行动。

2. **多模态分析**：
   - 使用 `ChatOpenAI` 结合 `HumanMessage` 中的 `image_url` 实现视觉检测。

3. **流式输出 (astream_events)**：
   - 利用 LangGraph 的 `astream_events` API 实现 SSE 流式传输，向前端实时推送思考过程。

## 🛠️ Tool 编写指南

### Tool 架构说明

本项目采用 LangChain 标准的工具定义模式，以便于 LLM 理解和调用。

```python
class ImageDetectInput(BaseModel):
    task_id: str = Field(..., description="任务唯一标识符")
    image_base64: Optional[str] = Field(None, description="Base64 图像")
    # ... 其他字段

class VisualAnomalyTool(BaseTool):
    name: str = "visual_anomaly_detection"
    description: str = "用于通过图像分析设备异常..."
    args_schema: Type[BaseModel] = ImageDetectInput

    async def _arun(self, **kwargs: Any) -> str:
        # 执行逻辑
        return result_json
```

### 关键：Executor 的自动补全机制
为了降低 Planner 的心智负担，`executor_node` 会自动从 `DetectionState.task` 中提取 `task_id`、`asset_id` 和 `image_base64` 注入到工具参数中。因此，编写工具时应确保这些参数是可选的或在 `_arun` 中能妥善处理。

### 如何编写新的 Tool

#### 1. 继承 `BaseTool` 并实现 `run` 方法

**示例：实现一个真实的 HTTP 异常检测工具**

```python
# app/tools/anomaly_detection.py

import httpx
from typing import Optional
from app.schemas.detection import DetectionTask, DetectionResult, ToolResponse
from app.exceptions.base import ExternalServiceError, ToolExecutionError
from app.config.settings import settings

class HttpAnomalyDetectionTool(BaseTool):
    """通过 HTTP 调用外部异常检测服务"""
    
    name = "http_anomaly_detection"
    
    def __init__(self, service_url: Optional[str] = None):
        """
        参数:
        - service_url: 外部服务 URL（可从 settings 读取）
        """
        self.service_url = service_url or getattr(settings, 'anomaly_detection_url', None)
        if not self.service_url:
            raise ConfigurationError("anomaly_detection_url not configured")
    
    async def run(self, task: DetectionTask) -> ToolResponse:
        """调用外部 HTTP 服务执行异常检测"""
        try:
            async with httpx.AsyncClient(timeout=30.0) as client:
                # 构造请求体
                payload = {
                    "task_id": task.task_id,
                    "asset_id": task.asset_id,
                    "start_time": task.start_time,
                    "end_time": task.end_time,
                    "data": task.parameters.get("data", []),  # 从 parameters 中提取数据
                    "threshold": task.parameters.get("threshold", 0.5)
                }
                
                # 发送 POST 请求
                response = await client.post(
                    f"{self.service_url}/detect",
                    json=payload,
                    headers={"Content-Type": "application/json"}
                )
                response.raise_for_status()  # 抛出 HTTP 错误
                
                # 解析响应
                result_data = response.json()
                result = DetectionResult(
                    task_id=result_data["task_id"],
                    status=result_data.get("status", "success"),
                    anomalies=result_data.get("anomalies", []),
                    summary=result_data.get("summary"),
                    metadata=result_data.get("metadata", {})
                )
                
                return ToolResponse(
                    tool_name=self.name,
                    success=True,
                    result=result
                )
                
        except httpx.HTTPStatusError as e:
            raise ExternalServiceError(
                message=f"HTTP service returned {e.response.status_code}",
                details={"url": self.service_url, "status_code": e.response.status_code}
            )
        except httpx.RequestError as e:
            raise ExternalServiceError(
                message=f"Failed to connect to detection service",
                original_error=e
            )
        except Exception as e:
            raise ToolExecutionError(
                tool_name=self.name,
                arguments={"task_id": task.task_id},
                error=e
            )
```

#### 2. 在配置中添加服务 URL（`app/config/settings.py`）

```python
class Settings(BaseSettings):

    app_name: str = "industrial-anomaly-agent"
    log_level: str = "INFO"
    
    # 新增：异常检测服务 URL
```

#### 3. 在工作流节点中使用新工具（`app/core/graph.py`）

```python
async def anomaly_detect_node(state: DetectionState) -> DetectionState:
    # 根据配置选择工具（可以从 settings 或 task.parameters 中读取）
    tool_type = state.task.parameters.get("tool_type", "mock")
    
    if tool_type == "http":
        tool = HttpAnomalyDetectionTool()
    else:
        tool = MockAnomalyDetectionTool()
    
    response = await tool.run(state.task)
    if response.success and response.result:
        state.result = response.result
        state.logs.append(f"Anomaly detection completed using {tool.name}")
    else:
        state.errors.append(response.error or "Unknown tool error")
    return state
```

### Tool 编写最佳实践

1. **错误处理**：
   - 使用项目统一的异常类型（`ExternalServiceError`、`ToolExecutionError`）
   - 记录详细的错误上下文（URL、状态码、原始异常）

2. **超时控制**：
   - 使用 `httpx.AsyncClient(timeout=30.0)` 设置超时
   - 避免工具执行时间过长影响整个工作流

3. **日志记录**：
   - 在 `state.logs` 中记录工具执行情况
   - 使用 `app.utils.logging` 记录详细日志

4. **参数验证**：
   - 在 `run` 方法开始处验证 `task` 参数
   - 使用 Pydantic 模型确保类型安全

## 🚀 后续代码补充方向

### 1. 集成 LangChain 调用 LLM（优先级：高）

**目标**：在 `summarize_node` 中使用 LangChain 调用 LLM 生成诊断建议

**步骤**：

1. **安装 LangChain OpenAI 集成**：
   ```bash
   pip install langchain-openai
   ```

2. **在 `app/config/settings.py` 添加 LLM 配置**：
   ```python
   class Settings(BaseSettings):
       # ... 现有配置 ...
       
       # LLM 配置
       openai_api_key: str = ""
       llm_model: str = "gpt-4o-mini"
       llm_temperature: float = 0.3
   ```

3. **创建 Prompt 模板**（`app/prompts/summarize.py`）：
   ```python
   from langchain.prompts import ChatPromptTemplate
   
   SUMMARIZE_PROMPT = ChatPromptTemplate.from_messages([
       ("system", """你是一个工业异常检测专家。请根据检测到的异常数据，
       生成一段通俗易懂的诊断建议，包括：
       1. 异常类型和严重程度
       2. 可能的原因分析
       3. 建议的处理措施
       
       使用中文回答，语言要专业但易懂。"""),
       ("user", """检测任务 ID: {task_id}
       资产 ID: {asset_id}
       时间范围: {start_time} 至 {end_time}
       
       检测到的异常：
       {anomalies}
       
       请生成诊断建议。""")
   ])
   ```

4. **实现 `summarize_node`**（`app/core/graph.py`）：
   ```python
   from langchain_openai import ChatOpenAI
   from app.prompts.summarize import SUMMARIZE_PROMPT
   from app.config.settings import settings
   from app.exceptions.base import ModelError
   
   async def summarize_node(state: DetectionState) -> DetectionState:
       """使用 LLM 生成诊断建议"""
       if not state.result:
           state.logs.append("No result to summarize")
           return state
       
       try:
           # 初始化 LLM
           llm = ChatOpenAI(
               model=settings.llm_model,
               temperature=settings.llm_temperature,
               api_key=settings.openai_api_key
           )
           
           # 构造 Prompt
           prompt = SUMMARIZE_PROMPT.format_messages(
               task_id=state.task.task_id,
               asset_id=state.task.asset_id,
               start_time=state.task.start_time,
               end_time=state.task.end_time,
               anomalies=state.result.anomalies
           )
           
           # 调用 LLM
           response = await llm.ainvoke(prompt)
           
           # 更新结果
           state.result.summary = response.content
           state.logs.append("LLM summary generated")
           
       except Exception as e:
           raise ModelError(
               message="Failed to generate summary",
               model_name=settings.llm_model,
               original_error=e
           )
       
       return state
   ```

### 2. 实现检查点持久化（优先级：中）

**目标**：实现 `app/memory/checkpoint.py` 的 `CheckpointStore`，支持状态持久化

**步骤**：

1. **实现内存检查点**（用于开发测试）：
   ```python
   # app/memory/checkpoint.py
   
   from typing import Dict, Optional
   from app.memory.state import DetectionState
   
   class MemoryCheckpointStore(CheckpointStore):
       """内存检查点存储（仅用于开发）"""
       
       def __init__(self):
           self._store: Dict[str, DetectionState] = {}
       
       def save(self, state: DetectionState):
           """保存状态"""
           self._store[state.task.task_id] = state
       
       def load(self, task_id: str) -> Optional[DetectionState]:
           """加载状态"""
           return self._store.get(task_id)
   ```

2. **实现 Redis 检查点**（用于生产）：
   ```python
   import json
   import redis.asyncio as redis
   from app.memory.state import DetectionState
   
   class RedisCheckpointStore(CheckpointStore):
       """Redis 检查点存储"""
       
       def __init__(self, redis_url: str = "redis://localhost:6379"):
           self.redis_client = redis.from_url(redis_url)
       
       async def save(self, state: DetectionState):
           """保存状态到 Redis"""
           key = f"checkpoint:{state.task.task_id}"
           value = state.model_dump_json()
           await self.redis_client.setex(key, 3600, value)  # 1小时过期
       
       async def load(self, task_id: str) -> Optional[DetectionState]:
           """从 Redis 加载状态"""
           key = f"checkpoint:{task_id}"
           value = await self.redis_client.get(key)
           if value:
               return DetectionState.model_validate_json(value)
           return None
   ```

3. **在 LangGraph 中启用检查点**（`app/core/agent.py`）：
   ```python
   from langgraph.checkpoint.memory import MemorySaver
   from app.memory.checkpoint import MemoryCheckpointStore
   
   def build_graph(checkpoint_store=None):
       """构建并编译检测工作流图"""
       graph = StateGraph(DetectionState)
       # ... 添加节点和边 ...
       
       # 启用检查点
       if checkpoint_store is None:
           checkpoint_store = MemorySaver()  # LangGraph 内置内存存储
       
       return graph.compile(checkpointer=checkpoint_store)
   ```

### 5. 添加数据验证和预处理节点（优先级：中）

**在 `load_data_node` 中添加数据验证**：

```python
async def load_data_node(state: DetectionState) -> DetectionState:
    """加载并验证数据"""
    if not state.task:
        raise DataMissingError("DetectionTask missing")
    
    # 验证时间范围
    from datetime import datetime
    start = datetime.fromisoformat(state.task.start_time.replace('Z', '+00:00'))
    end = datetime.fromisoformat(state.task.end_time.replace('Z', '+00:00'))
    if start >= end:
        raise DataMissingError("start_time must be before end_time")
    
    # 验证数据
    data = state.task.parameters.get("data", [])
    if not data or len(data) == 0:
        raise DataMissingError("data parameter is required and cannot be empty")
    
    state.context["loaded"] = True
    state.context["data_points"] = len(data)
    state.logs.append(f"Data loaded: {len(data)} points")
    return state
```
